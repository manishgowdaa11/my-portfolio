## Brand & Style

This design system establishes a high-performance, forward-looking aesthetic tailored for an Artificial Intelligence and Machine Learning specialist. Merging deep cybernetic tones with sophisticated glassmorphism, it strikes a deliberate balance between academic rigor in algorithmic engineering and state-of-the-art interactive craft.

### Brand Personality & Emotional Impact
- **Analytical & Visionary:** Clean, systematic structures reflect algorithmic clarity, high-dimensional data processing, and technical competence.
- **Electric & Immersive:** Deep void canvases juxtaposed with luminescent cyan and violet energy convey high intellect, ambition, and digital precision.
- **Crafted & Tactile:** Micro-interactions, soft chromatic glows, and translucent glass layers create depth without visual noise or gimmickry.

### Visual Style Direction
The aesthetic fuses **Glassmorphism** with **Technical Minimalism**:
- Translucent backdrop-blurred surfaces layered over deep spatial substrates.
- Faint dot-grid arrays and radial gradient meshes simulating computational coordinate planes.
- Razor-sharp typographic hierarchy using technical geometric display type counterbalanced by highly legible, utilitarian body copy.

## Colors

The palette revolves around deep cosmic depths, energized by focused violet and electric cyan-blue emitters.

### Canvas & Surface Architecture
- **Primary Void Canvas (`#080B14`):** Base canvas layer for global full-bleed screens.
- **Secondary Canvas (`#0D1322`):** Elevated structural sections, alternating layout bands, and structural sidebars.
- **Translucent Card Surface (`#111827`):** Elevated containers, rendered at `80%` to `90%` opacity paired with `backdrop-filter: blur(16px)` to absorb the ambient under-glows.
- **Edge Highlighting:** Thin geometric strokes using `rgba(139, 92, 246, 0.15)` on idle containers, stepping up to `rgba(56, 189, 248, 0.4)` on interactive states.

### Accents & Illumination
- **Primary Accent (`#8B5CF6` - Neural Violet):** Serves as the primary focal identity, anchor action triggers, active tab states, and directional gradients.
- **Secondary Accent (`#38BDF8` - Electric Sky):** Signifies secondary interactive items, specialized algorithm benchmarks, and code syntax markers.
- **Tertiary Highlight (`#22D3EE` - Cyan Neon):** Reserved for live statuses, model convergence tags, metrics, and cursor trail points.

### Typography & Content
- **Main Text (`#F8FAFC`):** Primary headings, pivotal project titles, and high-priority code metrics.
- **Secondary Text (`#94A3B8`):** Body paragraphs, architecture explanations, and date stamps.
- **Muted Subtext (`#64748B`):** Metadata, icon fills, and grid coordinates.

## Typography

Typography unifies structural engineering with editorial finesse:
- **Headings & Display Roles:** Cast in `Space Grotesk` to imbue technical geometry, scientific precision, and modernist tension.
- **Body & Continuous Copy:** Rendered in `Inter` for optimal optical clarity, high legibility across dark background modes, and neutral reading flow.
- **Labels, Badges, and Metadata:** Rendered in `Space Grotesk` with slightly expanded letter-spacing to emphasize technical categorization (e.g., PyTorch, Transformers, CUDA, 3rd Sem CSE).

## Layout & Spacing

The layout philosophy adheres to a strict 12-column fluid grid framed within a maximum container width of `1280px`.

### Grid & Breakpoints
- **Mobile (< 768px):** 4 fluid columns, `16px` outer margins, `16px` gutters. Single-column stacked flows for project showcases and tech matrices.
- **Tablet (768px - 1024px):** 8 fluid columns, `32px` outer margins, `24px` gutters. Two-column cards for projects and academic credentials.
- **Desktop (> 1024px):** 12 fluid columns, `48px` outer margins, `32px` gutters. Complex multi-span layouts (e.g., 7-column project previews alongside 5-column technical specs).

### Grid Dot & Spatial System
Sections utilize an underlaid computational dot matrix:
- Dot matrix size: `1px` dots spaced on a `24px` grid pattern using `rgba(148, 163, 184, 0.08)`.
- Radial gradient mask applied on parent sections to prevent dots from cluttering canvas borders or competing with visual text hierarchy.

## Elevation & Depth

Visual hierarchy does not use standard dropshadows, but rather **luminescent layers and atmospheric lighting**:

### Elevation Levels
- **Ground (Canvas):** `#080B14` flat background with optional ambient radiant radial gradients (e.g., 400px blurred circular highlights in `#8B5CF6` at 8% opacity).
- **Level 1 (Structural Sections & Drawers):** `#0D1322` with a 1px border of `rgba(255, 255, 255, 0.04)`.
- **Level 2 (Glassmorphism Cards):** Surface `#111827` at `85%` opacity, `backdrop-filter: blur(16px)`, encircled by a thin border `1px solid rgba(139, 92, 246, 0.15)`. Ambient soft shadow: `0 8px 32px 0 rgba(0, 0, 0, 0.36)`.
- **Level 3 (Interactive Hover / Focus State):** Surface rises dynamically: border elevates to `rgba(56, 189, 248, 0.45)`, backed by a dual glow:
  - Inner glow: `inset 0 0 16px rgba(139, 92, 246, 0.08)`.
  - Outer radial halo: `0 12px 40px -8px rgba(139, 92, 246, 0.25)`.
- **Level 4 (Floating Modals & Code Drawers):** High-opacity glass `#111827` at `95%` opacity, `backdrop-filter: blur(24px)`, `box-shadow: 0 20px 60px rgba(0, 0, 0, 0.7), 0 0 1px 1px rgba(56, 189, 248, 0.3)`.

## Shapes

The geometric framework leverages calibrated curvature that balances technical precision with modern software elegance.

- **Base Radius (0.5rem / 8px):** Code snippets, inputs, interactive buttons, and table rows.
- **Large Radius (1rem / 16px):** Project cards, architecture visualizers, interactive sandbox panels.
- **Extra Large Radius (1.5rem / 24px):** Hero featured showcase modules and contact containment modals.
- **Full Pill Radius (9999px):** Status badges, dynamic categorical chips, tech stack identifiers, and floating control docks.

## Components

### Buttons
- **Primary Cyber Button:** Gradient fill sweeping horizontally from `#8B5CF6` to `#38BDF8`. Text `#F8FAFC`, typography `label-nav`. Border radius `8px`. Box-shadow: `0 0 20px rgba(139, 92, 246, 0.35)`. Hover transition via Framer Motion: scale `1.02`, glow intensity boosts to `0 0 28px rgba(56, 189, 248, 0.5)`.
- **Secondary Ghost Button:** Background transparent with glass fill `rgba(17, 24, 39, 0.6)`, `backdrop-filter: blur(8px)`. Border `1px solid rgba(139, 92, 246, 0.3)`. Main text `#F8FAFC`. On hover, border switches to `#38BDF8` with a subtle background shift to `rgba(56, 189, 248, 0.08)`.

### Cards & Project Showcases
- **Glass Container:** Background `rgba(17, 24, 39, 0.85)` with `16px` backdrop-filter blur.
- **Border Treatment:** `1px solid rgba(139, 92, 246, 0.15)`.
- **Interactive State (Framer Motion):** Smooth upward lift `y: -4px` with spring stiffness 300, border transitioning to a cyan-violet gradient sheen via pseudo-element opacity.

### Badges & Technology Chips
- **Pill Badges:** Pill shape (`9999px`), padding `4px 12px`. Space Grotesk `tech-badge` uppercase.
- **Colorway:** Background `rgba(139, 92, 246, 0.1)`, text `#38BDF8`, subtle border `1px solid rgba(56, 189, 248, 0.2)`.
- **Live Indicator Dot:** For AI model demo tags, an inner pulsing circle (`6px`) with tertiary cyan `#22D3EE` and Framer Motion ping animation.

### Input Fields & Terminal Console
- **Input Text:** Background `rgba(13, 19, 34, 0.9)`, border `1px solid rgba(148, 163, 184, 0.2)`. Text `#F8FAFC`, placeholder `#64748B`. Focused state: border `#38BDF8`, box-shadow `0 0 12px rgba(56, 189, 248, 0.25)`.
- **Interactive Terminal Sandbox:** Monospaced and Space Grotesk integrated area for terminal commands or model inference execution, featuring `#080B14` inset fill, header window dots (red, yellow, green), and syntax highlighting in `#38BDF8`, `#8B5CF6`, and `#22D3EE`.

### Lists & Academic Milestones
- **Timeline / Progression Track:** A vertical `2px` path with an active gradient line connecting nodes.
- **Milestone Nodes:** Double concentric circles; outer ring `rgba(139, 92, 246, 0.25)`, inner glowing core `#38BDF8` indicating semester progression and ML research papers.
